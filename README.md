**🟢 STATUS: ACTIVE INVESTIGATION** — open case, multi-hop flood routing in progress

An Android BLE mesh chat platform engineered for total infrastructure blackouts — zero cellular towers, zero Wi-Fi, zero internet. Relays forward end-to-end encrypted packet envelopes without possessing the private keys to read them.

### 🛡️ Adversarial Defense Matrix
- **Eavesdropping on Relays:** Ephemeral Curve25519 Diffie-Hellman (`X25519`). Relays handle raw byte envelopes blindly.
- **Replay & Flooding Attacks:** Monotonic sliding-window sequence tracking with TTL decrements (max 7 hops).
- **Physical Device Seizure:** `SQLCipher` (AES-256-CBC) database encryption at rest with memory-zeroized panic wipe.
- **Corrupted Packets:** Chunked transport with SHA-256 block hash verification and selective ACK/NACK retransmissions.
- **Field Benchmark:** Wall-penetration tested through concrete at ~20m distance with near-zero latency.
